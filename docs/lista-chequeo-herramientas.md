# 🛠️ Lista de Chequeo: Herramientas Esenciales (Finca Pequeña)

Antes de ir al lote, asegúrate de tener el equipo básico. Sin herramientas, el trabajo rinde la mitad y el cansancio es el doble.

---

## 🌾 1. Para Preparación y Limpieza
* [ ] **Machete "Rula" o "Costeño":** La herramienta #1 para todo. Mantener siempre bien afilado.
* [ ] **Azadón:** Fundamental para el aporque del maíz y la limpieza de la yuca.
* [ ] **Pala Redonda y de Punta:** Para hacer drenajes, huecos para el ñame y mover abono.
* [ ] **Barra o Barretón:** Para romper suelo duro o hacer los hoyos de los postes.

## 🌽 2. Para Siembra y Cuidado
* [ ] **Chuzo o Sembrador:** Para el maíz y frijol.
* [ ] **Bomba de Espalda (20L):** Para aplicar los foliares orgánicos y el control de plagas natural.
* [ ] **Limas y Piedra de Afilar:** Un machete sin filo es un peligro y hace perder tiempo.

## 🐄 3. Para Ganadería y Cercas
* [ ] **Martillo de Uña y Alicate:** Para templar alambre y arreglar portones.
* [ ] **Cavador (Hoyo-Hoyo):** Si vas a sembrar estacones para el ganado o el ñame.
* [ ] **Cuerda o Lazo (Mecate):** Siempre tener uno a la mano para manejar animales.

## 📦 4. Equipo de Protección (Seguridad Social)
* [ ] **Botas de Caucho:** Protección contra humedad y serpientes.
* [ ] **Sombrero de Ala Ancha:** El sol del Cesar no perdona.
* [ ] **Guantes de Carnaza:** Para manejar alambre de púas o madera espinosa.

---
### 💡 Consejo de Dentalmovilr4:
**"Herramienta guardada, herramienta que dura"**. Después de usar la bomba de espalda, lávala bien para que no se tapen las boquillas. Al machete, pásale un poco de aceite si lo vas a guardar por mucho tiempo para que no se oxide.
