# 🌱 Guía de Cultivo: Yuca (Manihot esculenta)

## 📋 Generalidades
* **Suelo:** Prefiere suelos sueltos y bien drenados.
* **Semilla:** Usar cangres (estacas) de plantas maduras y sanas (20-25 cm).

## 🐛 Manejo de Plagas
* **Mosca Blanca:** Monitoreo constante en el envés de las hojas.
* **Ácaros:** Comunes en temporadas secas.

## 💰 Rentabilidad
La yuca permite doble propósito: consumo fresco o uso industrial (almidón/harina).
