# 💰 Ficha Técnica: Costos y Rentabilidad por Hectárea (Estimado Cesar)

Esta ficha es una guía para proyectar la inversión y el retorno esperado. *Nota: Los precios varían según la temporada y el municipio.*

---

## 🌽 1. Maíz Tecnificado (1 Ha)
**Meta de Rendimiento:** 5 a 7 Toneladas/Ha.

| Ítem | Descripción | Costo Est. (COP) |
| :--- | :--- | :--- |
| **Semilla** | Híbrido de alto rendimiento (2 bolsas) | $1.200.000 |
| **Preparación** | Arado y rastrillado (Maquinaria) | $600.000 |
| **Fertilización** | Triple 15, Urea y elementos menores | $2.500.000 |
| **Mano de Obra** | Siembra, fumigación y limpia | $1.500.000 |
| **Cosecha** | Recolección y transporte | $800.000 |
| **TOTAL INVERSIÓN** | | **$6.600.000** |

📊 **Rentabilidad:** Si vendes 6 Ton a $1.300.000 c/u = **$7.800.000**. 
*Utilidad estimada: $1.200.000 por Ha.*

## 🌱 2. Yuca de Consumo (1 Ha)

| **Semilla** | 10 cargas de cangre seleccionado | $400.000 |
| **Preparación** | Caballoneo y limpieza | $500.000 |

| **Cosecha** | Arranque y cargue | $1.000.000 |
| **TOTAL INVERSIÓN** | | **$3.100.000** |

📊 **Rentabilidad:** Si vendes 12 Ton a $800.000 c/u = **$9.600.000**.

---

### 💡 Recomendaciones para mejorar el margen:
1. **Compra en volumen:** Unirse con otros productores para comprar fertilizantes baja los costos.
2. **Asociatividad:** Vender directamente a plazas o industrias evita al intermediario que se queda con la ganancia.
3. **Uso de Bio-insumos:** Producir tu propio abono orgánico reduce la dependencia de químicos caros.
